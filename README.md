# SmartDevice Embedded Systems Lab

## Installation
\`\`\`bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
\`\`\`

## Build
\`\`\`bash
docker-compose build
\`\`\`

## Run
\`\`\`bash
docker-compose up
\`\`\`

## Dependencies
- FastAPI
- SQLAlchemy
- Uvicorn
- WebSockets
- Pytest

## Usage
Navigate to http://localhost:8000/ to access the dashboard.
